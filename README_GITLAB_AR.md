# بناء WiFi Pilot عبر GitLab (مجانًا ضمن حدود الخطة)

هذا المشروع يتضمن `.gitlab-ci.yml` لبناء نسخة Debug APK عبر GitLab CI/CD. النسخة الناتجة تكون موقّعة بمفتاح Debug لأغراض الاختبار، وليست مفتاح إصدار خاصًا دائمًا.

## مهم
- لم يتم اختبار خط البناء هذا في هذه الحزمة؛ قد يتطلب تعديلًا إذا ظهرت أخطاء بناء.
- لا تضع كلمات مرور أو مفاتيح توقيع خاصة داخل المستودع.
- إذا كان المستودع عامًا، فالمصدر سيكون متاحًا للآخرين.

بعد رفع الملفات إلى مشروع GitLab، افتح Build > Pipelines وانتظر انتهاء البناء. عند نجاحه، افتح المهمة (job) ثم نزّل Artifact باسم `app-debug.apk`.
