# WiFi Pilot — مشروع Android

تطبيق تجريبي أصلي بلغة Kotlin لإدارة وتحليل شبكات Wi‑Fi، بواجهة عربية، وبدون صلاحيات root.

## التوافق
- minSdk: 23 (Android 6.0)
- compileSdk: 35
- targetSdk: 35
- مناسب مبدئيًا لـ Android 14؛ يجب البناء والتجربة على الجهاز للتأكد.

## البناء من الهاتف
الطريقة المقترحة: AndroidIDE (إن كان متاحًا ومناسبًا لإصدار Android لديك).
1. فك ضغط WiFiPilot.zip في مجلد يسهل الوصول إليه.
2. افتح مجلد المشروع الذي يحتوي على `settings.gradle.kts` في AndroidIDE.
3. وافق على تثبيت/تنزيل Gradle وAndroid SDK Platform 35 عند الطلب.
4. نفّذ Gradle Sync ثم Build/Assemble Debug APK.
5. الناتج المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK إلى الهاتف وثبّته بعد السماح بمصدر التثبيت الذي استخدمته.

إذا لم يستطع AndroidIDE استخدام إصدار Gradle أو JDK المطلوب، لا تغيّر عشوائيًا إصدارات الإضافات؛ أرسل نص الخطأ لتحديد الإصدار المتوافق.

## الوظائف الحالية
- طلب مسح شبكات Wi-Fi وعرض النتائج المتاحة من Android.
- SSID، قوة الإشارة dBm، تقدير مئوي، تردد/قناة، ومؤشرات الحماية.
- تفاصيل الشبكة النشطة عبر ConnectivityManager: IP، المسارات/البوابة، DNS وHTTP proxy عند إتاحتها.
- اختبار تشخيصي مبسط للبوابة وعنوان عام وDNS.
- مخطط أعمدة لقوة إشارة الشبكات.
- أزرار تفتح إعدادات Wi-Fi وPrivate DNS وإعدادات الشبكة.

## حدود Android
- لا يقرأ كلمات مرور الشبكات.
- لا يغيّر DNS أو Proxy مباشرة؛ يفتح إعدادات النظام.
- نتائج المسح تعتمد على أذونات الموقع/الأجهزة القريبة، تفعيل الخدمات، قيود Android وتكرار المسح.
- اختبار `isReachable` قد يفشل حتى مع وجود اتصال لأن بعض الشبكات تمنع ICMP؛ النتيجة ليست حكمًا قاطعًا على الإنترنت.
- هذا مشروع مصدر أولي؛ لا يوجد APK مبني أو مختبر ضمن حزمة التسليم الحالية.
